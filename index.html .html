Materi HTML & CSS

HTML

HyperText Markup Language

HTML digunakan untuk membuat struktur dan isi website, seperti judul, paragraf, gambar, dan tombol.

CSS

Cascading Style Sheets

CSS digunakan untuk mengatur tampilan website, seperti warna, ukuran, font, posisi, dan desain.

Penjelasan singkat

HTML = isi dan struktur website.

CSS = tampilan website.

Materi Python & JavaScript

PYTHON

Python

Python tidak memiliki kepanjangan resmi. Python adalah bahasa pemrograman untuk membuat berbagai program, mengolah data, membuat AI, dan aplikasi.

JAVASCRIPT

JavaScript

JavaScript juga tidak memiliki kepanjangan resmi. JavaScript membuat website menjadi interaktif, misalnya tombol yang bisa melakukan sesuatu, animasi, dan game sederhana.

Cara gampang mengingat

HTML → struktur website

CSS → tampilan website

JavaScript → interaksi website

Python → membuat berbagai program dan aplikasi
